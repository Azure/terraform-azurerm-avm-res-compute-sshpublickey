# terraform-azurerm-avm-res-compute-sshpublickey

Manages a SSH Public Key resource in Azure.

This module requires AzureRM 4.x. When upgrading from 3.x, specify `subscription_id` in your provider configuration or set `ARM_SUBSCRIPTION_ID`; relying on the active Azure CLI subscription is no longer supported. Resource addresses and inputs are unchanged.
